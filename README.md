# Sohil Boyi — QR menyu

Sohil Boyi mehmonxonasi restoranining mobil, planshet va kompyuter uchun moslashuvchan menyu sahifasi (UZ / RU / EN).

- Bitta `index.html`, qo'shimcha kutubxonalarsiz (faqat Google Fonts).
- Rasmlar: `img/` papkasida (`burrata`, `mastava`, `sibas`, `bayram-oshi`, `fondan`, `limonad` — `.jpg`). Fayl bo'lmasa, lagan joyi bo'sh qoladi.
- Taom va narxlarni `index.html` ichidagi `M` massivida o'zgartiring.
- Figma maketi: https://www.figma.com/design/taC9CjseTy6me8NOOZLxqY

## Vercel'ga joylash

1. vercel.com → Add New → Project → shu repozitoriyani tanlang.
2. Framework Preset: Other. Build command va Output directory bo'sh qoladi.
3. Deploy. Chiqqan doimiy manzildan QR kod yasang.
